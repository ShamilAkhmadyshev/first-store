# First Store

A React e-commerce demo using Fake Store API for products and Firebase Authentication for login/registration.

## Highlights
- 🛍️ Product catalog by categories (electronics, jewelry, men’s/women’s clothing)
- 🔎 Search and basic sorting (price ↑/↓)
- 🧾 Product cards with mock rating/stock badges
- 🧺 Cart basics (UI components present in codebase)
- 🔐 Auth with Firebase Identity Toolkit (email/password)
- 🔔 Toast notifications (react-toastify)
- 💅 Bootstrap UI + bootstrap-icons

## Tech Stack
- React 18 (Create React App)
- React Router v6
- Axios
- Bootstrap, bootstrap-icons
- React-Toastify
- Firebase Identity Toolkit (Auth REST)
- Firebase Realtime Database (REST via `.json` endpoints)
- gh-pages (optional deploy)
